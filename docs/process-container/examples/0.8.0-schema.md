# ProcessContainer schema 0.8 examples

Schema 0.8 adds IP/CIDR, protocol, and port egress rules; coarse inbound
toggles; runtime proxy metadata; and an identity-scoped ProcessContainer proxy
peer. See [Process Container Networking Configuration](../networking.md) for
Windows enforcement details and
[MXC Network Configuration](../../sandbox-policy/v2/networking.md) for the
shared policy semantics.

## Direct egress

This policy permits only TCP/443 to the selected CIDR, except for one excluded
address. All other egress, LAN/private-network inbound, and host-loopback
inbound connections are denied.

```jsonc
{
  "version": "0.8.0-dev",
  "containment": "processcontainer",
  "network": {
    "egress": {
      "default": "deny",
      "allow": [
        {
          "to": [
            {
              "cidr": "140.82.112.0/20",
              "except": [ "140.82.112.2/32" ]
            }
          ],
          "ports": [ { "protocol": "tcp", "port": 443 } ]
        }
      ],
      "deny": []
    },
    "ingress": {
      "default": "deny",
      "hostLoopback": "deny"
    }
  }
}
```
