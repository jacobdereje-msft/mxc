# ProcessContainer schema 0.8 configuration

See the shared [0.7-to-0.8 network schema comparison](../../sandbox-policy/v2/networking-0.7.0-vs-0.8.0.md)
for egress, ingress, and proxy endpoint changes. This page covers the
ProcessContainer-specific proxy peer.

## Contained proxy

`allowedProxyPeer` identifies the packaged or unpackaged AppContainer that
hosts the proxy.

```jsonc
{
  "version": "0.8.0-dev",
  "containment": "processcontainer",
  "runtimeConfig": {
    "networkProxy": "http://127.0.0.1:8080"
  },
  "processContainer": {
    "network": {
      "allowedProxyPeer": "agent-proxy"
    }
  }
}
```

| Field | Value |
|---|---|
| `runtimeConfig.networkProxy` | HTTP/S loopback URL with an explicit port |
| `processContainer.network.allowedProxyPeer` | Package family name or AppContainer profile name |

The omitted `network` block uses deny defaults. See
[Process Container Networking Configuration](../networking.md) for Windows
enforcement details.
