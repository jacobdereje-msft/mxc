# ProcessContainer schema 0.7 examples

Schema 0.7 and earlier use the legacy flat network object. It controls the
default outbound posture, enforcement mechanism, host allow/block lists,
inbound listening, and an optional proxy.

## Deny-by-default with an allow list

```jsonc
{
  "version": "0.7.0",
  "containment": "processcontainer",
  "network": {
    "defaultPolicy": "block",
    "enforcementMode": "both",
    "allowedHosts": [
      "api.github.com",
      "140.82.112.0/20"
    ],
    "allowLocalNetwork": false
  }
}
```

## Allow-by-default with a block list

```jsonc
{
  "version": "0.7.0",
  "containment": "processcontainer",
  "network": {
    "defaultPolicy": "allow",
    "enforcementMode": "firewall",
    "blockedHosts": [
      "malicious.example"
    ],
    "allowLocalNetwork": false
  }
}
```

## Legacy field reference

| Field | Values | Meaning |
|---|---|---|
| `defaultPolicy` | `"block"` (default), `"allow"` | Outbound posture when no host rule matches |
| `enforcementMode` | `"capabilities"` (default), `"firewall"`, `"both"` | Requested enforcement mechanism |
| `allowedHosts` | Hostnames, IP addresses, or CIDRs | Outbound exceptions when `defaultPolicy` is `"block"` |
| `blockedHosts` | Hostnames or IP addresses | Outbound exceptions when `defaultPolicy` is `"allow"` |
| `allowLocalNetwork` | `false` (default), `true` | Allows binding/listening on local IPs and accepting inbound connections where supported |
| `proxy` | Exactly one proxy form below | Optional cooperative HTTP/S proxy configuration |

Backend support for individual fields varies. In particular,
`allowLocalNetwork` is part of the 0.7 schema but is not enforced by the
ProcessContainer compatibility path.

## Optional proxy

The proxy is one optional part of the 0.7 network object, not the complete
network policy. The ProcessContainer compatibility path injects cooperative
`HTTP_PROXY` and `HTTPS_PROXY` variables for clients that honor them; it does
not use the 0.8 proxy-peer contract.

Use exactly one proxy form.

### Existing localhost proxy

```jsonc
{
  "version": "0.7.0",
  "containment": "processcontainer",
  "network": {
    "proxy": {
      "localhost": 8080
    }
  }
}
```

### Proxy URL

```jsonc
{
  "version": "0.7.0",
  "containment": "processcontainer",
  "network": {
    "proxy": {
      "url": "http://127.0.0.1:8080"
    }
  }
}
```

### Built-in test proxy

```jsonc
{
  "version": "0.7.0",
  "containment": "processcontainer",
  "network": {
    "proxy": {
      "builtinTestServer": true
    }
  }
}
```

The built-in proxy is for integration testing only and requires the
testing-feature opt-in.

See [Process Container Networking Configuration](../networking.md) for Windows
enforcement details.
